# 源码带读

遵守仓库 AGENTS.md。以仓库根为基准，涉及整体调用关系时先读 `docs/嵌入式软件架构.md`，并以当前源码核实。

1. 从用户指定的 demo、文件或符号开始，查 CMake 确认是否参与构建。同名模块有多份副本，引用时带上 demo 路径。
2. 默认只读，每次讲一个函数或连贯的小块。先说明它解决什么问题，再解释关键语句；语法知识补充到能读懂该块即可。
3. 沿必要调用方说明：谁调用、在哪个线程、输入输出、错误如何传递。涉及图像时区分压缩包、MPP 帧、YUV、BGR 和模型输入。
4. 明确每个资源是谁创建、谁持有、何时释放；区分 `cv::Mat` 赋值共享、clone 拷贝和 move 转移，不能把对象不同等同于像素独立。
5. 给出实际路径、符号和必要行号。注释与实现不一致时说明；遇到相关缺陷可简要指出证据，不扩成未经要求的全仓审查或修复。
6. 带读结束给 1–3 个针对当前代码的理解题，先不公布答案；用户回答后结合代码纠正。用户要求直接答案或跳过练习时遵从。

示例请求：`$source-reading-tutor 带我读 project1/demo_multhread_decode_infer/demo_multhread_decode_infer.cpp 的 main，每次只讲一小段。`
